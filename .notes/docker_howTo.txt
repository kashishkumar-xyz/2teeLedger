 Here's how to use it:

   1. Build the Docker image (if you haven't already or if the 
      `Dockerfile` changed):
   1     cd /home/kaz/Dev/rust/_current/2teeLedger
   2     docker-compose build

   2. Start the interactive shell:
   1     docker-compose run --rm cli
      This command will start a new container based on your cli service 
  definition, and because we set entrypoint: ["bash"], you will 
  immediately be presented with a bash prompt inside the container.

   3. Execute your CLI commands interactively:
      Once inside the container's shell, you can run your cli application
   directly. The executable is located at /app/cli.

      For example:

       * Initialize the database:

   1         /app/cli init-db --db-path /app/data/db/ledger.db 
     --encryption-key "your_secret_key"

       * Add a transaction:

   1         /app/cli add --db-path /app/data/db/ledger.db 
     --encryption-key "your_secret_key" --person "Alice" --amount
     50 --date "2025-10-16" --note "Coffee"

       * List transactions:

   1         /app/cli list --db-path /app/data/db/ledger.db 
     --encryption-key "your_secret_key"

       * Get balance:

   1         /app/cli balance --db-path /app/data/db/ledger.db 
     --encryption-key "your_secret_key" --person "Alice"

      Remember to replace "your_secret_key" with your actual encryption 
  key. The database path inside the container is /app/data/db/ledger.db.

   4. Exit the shell:
      Type exit and press Enter to leave the container's shell. The --rm 
  flag will ensure the container is removed, but the ledger_data volume 
  (and thus your database) will persist.

  This setup gives you full interactive control within the isolated 
  Docker environment.
